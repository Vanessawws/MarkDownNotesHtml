# MarkDownNotesHtml

Note Harbor 是一个单文件 HTML 笔记应用，数据默认保存在浏览器 `localStorage` 中。

## 功能

- 新建、编辑、删除笔记
- 标题、正文和标签搜索
- 标签筛选、当前/归档筛选
- 置顶和归档
- Markdown 预览
- JSON 导入和导出

## 使用

直接打开根目录的 `index.html`，或用 GitHub Pages / 任意静态服务器托管本仓库。

GitHub Pages 启用后，首页地址为：

`https://vanessawws.github.io/MarkDownNotesHtml/`
